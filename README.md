
# Knowledge Management Platform

This project is a Knowledge Management Platform developed using **Laravel** (backend) and **Vue.js** (frontend). It provides robust features for creating, sharing, searching, and managing articles, files, and collaborative content within an organization.

## Features


- **Advanced Search**
  - ElasticSearch-powered global and contextual search
  - AI-assisted search and article creation
  - Search history and suggestions
- **Responsive UI** with Vue.js and Bootstrap

## Tech Stack

- **Backend:** Laravel, MySQL, ElasticSearch
- **Frontend:** Vue.js, Vuex, Vue Router, Bootstrap
- **Other:** PHPWord (for document processing), OpenAI integration

### Prerequisites

- PHP >= 8.0
- Composer
- Node.js & npm
- MySQL
- ElasticSearch
